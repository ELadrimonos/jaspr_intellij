Reports nested css() rules whose selector appends to the parent selector, such as &-active.

Since Jaspr 0.24, nested css() rules are rendered as native CSS nesting, which has no selector concatenation: css('.button', [css('&-active')]) used to produce .button-active and no longer matches it.

The quick-fix moves the rule out of its parent with the full selector, e.g. css('.button-active'). The inspection only runs when the package depends on Jaspr 0.24 or later.
